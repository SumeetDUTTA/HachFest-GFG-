# InsightBI | Instant Business Intelligence

A modern, premium SaaS-style frontend for a Conversational BI Dashboard built with **React.js + Vite**.

## 🚀 Features

- **Modern SaaS Design**: Clean, compact, and professional layout inspired by Vercel and Linear.
- **Conversational Analytics**: Natural language query interface to generate interactive dashboards.
- **Dynamic Charts**: Powered by Recharts for high-fidelity data visualization.
- **Strategic Insights**: AI-synthesized patterns and strategic recommendations.
- **Data Management**: Dedicated history and upload corpus management.

## 🛠️ Tech Stack

- **Frontend**: React.js (Vite)
- **Styling**: TailwindCSS + Vanilla CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Charts**: Recharts

## 📦 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open the browser**:
   Navigate to `http://localhost:5173` (or the port shown in your terminal).

## 📂 Project Structure

- `src/components`: Reusable UI components (Sidebar, Navbar, ChartCard, etc.)
- `src/pages`: Main page layouts (Dashboard, Insights, Settings, etc.)
- `src/layouts`: Dashboard structure and max-width containers.
- `src/styles`: Global CSS with Poppins typography and theme tokens.
- `src/data`: Mock datasets for prototyping.
